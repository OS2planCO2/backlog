# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in OS2planCO2, please report it responsibly by email to:

**os2planco2@os2.eu**

Please CC **security@os2.eu**.

Do not disclose security vulnerabilities publicly before they have been assessed and appropriately addressed.

## Security Policy and Procedures

OS2planCO2 follows the common security reporting and vulnerability handling practices established by the OS2 community.

For further information, please refer to the [OS2 Security Policy](https://www.os2.eu/sikkerhed).

OS2 does not operate a bug bounty program or offer financial rewards for vulnerability reports.
